## Notes for the owner (not decisions)

- **Mediation KIC-ARCH-MED-01** (2026-11-13) is at `docs/architecture/mediation/KIC-ARCH-MED-01/`. It recommends keeping OD-1's shape (OpenBot unmodified, pinned to a release tag rather than a commit, built-in Bots only) and raised OD-12 to OD-19. Its decision package (D5) lists which of its proposals are the owner's and which are within existing authority.
- **OD-6**, widened by the mediation and the security review: the Bots' own conversation with the model through OpenBot goes through the model shim. The shim now limits it in key-injection mode (commit `12a7626`): a cap per request, a limit on requests in flight and a persistent ceiling, and it refuses to start without a ceiling unless that is waived in so many words. **The figures are yours to set.**
- **OD-12**, what it takes: with OpenBot in front, "prepares only" is not automatic. Read at `v1.0.2`, not run: the team edition can run with no Bot computer, which is the simplest safe arrangement; the personal edition cannot be confined by configuration. `docs/security/CONFINEMENT-TEST-MATRIX.md` sets out what stands behind each control.
- **OD-8 / OD-15** remain yours; nothing was sent to CopilotKit and no paid service was started. Draft questions: `docs/decisions/LICENCE-QUESTIONS-COPILOTKIT.md`. Corrected by the second review of the mediation: self-hosting Intelligence on Kubernetes with a production licence is the documented production route; only the local evaluation on macOS is described as not for production. With the managed service, conversations are presumably kept by the vendor. The confinement findings point to the team edition for a client instance, which needs an identity provider.
- **OD-7**, corrected: OpenBot's first migration creates the `vector` extension and a later one drops it; OpenBot does no local vector search, but the database role must be able to create and drop the extension during migration.
- **OD-8**, sharpened: OpenBot's README states that Kubernetes or production use needs "a production Intelligence license beyond evaluation". Whether the pay-as-you-go plan is that licence for a client-owned, self-hosted instance is not confirmed by anything read.
- **OD-1** is decided provisionally and conditionally (see the table). This session built the parts that do not depend on it. The KIC MCP server and the model shim were exercised with the CopilotKit agent class on its own; they are designed for complete OpenBot too, but nothing has been run inside OpenBot. The tenant package passes OpenBot's validator and has not been loaded by a running OpenBot.
- **OD-2**: read access to `aeh` was refused again in this session. The harness was built from first principles and may duplicate it.
- **OD-3**: no live JEV transport exists in the code. Activation needs new code, a passed security gate and your authorisation.
- **OD-4**: the repository is still public, has no `main`, and has no branch protection. No pull request can be opened until a base branch exists.
- **OD-5**: ten independent agent reviews and one direct Mistral review were run and recorded against commit SHAs. Eight agent reviews and the Mistral review requested changes; the ninth approved `55a66f2` and the tenth, a delta review, approved `2537386`. All were commissioned inside this programme's sessions. The Mistral Code Review Bot's block-content fix is absent from its default branch; Codex is unavailable.
- **OD-6**: the published price for "Mistral Large" is $0.50 per million input tokens and $1.50 per million output tokens. The page does not say whether that applies to Large 4 or how reasoning tokens are billed. No spend ceiling has been set.
