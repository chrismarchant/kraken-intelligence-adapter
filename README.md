# Kraken Intelligence Companion (KIC)

A standalone campaign-preparation intelligence companion for LinkedIn content programmes. It interprets a brief, drafts and compares alternatives, supports editorial selection and assembles a programme package. It does not publish.

**Status:** KIC-00 (foundation and feasibility) presented for owner approval. No product code yet.
